# Dating App: React front end

The front end of a dating app, built with React, TypeScript and Vite.

## What is in it
- **Login page** (`src/page/login.tsx`).
- Tailwind CSS styling and a TypeScript + Vite project setup.

## Tech stack
React, TypeScript, Vite, Tailwind CSS.

## Run it locally
```bash
npm install
npm run dev
```

## Status
Project set-up and login screen. Sign-up, profiles and chat are the next steps.
